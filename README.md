# Dr. Maya Reynolds Therapy Website

A responsive therapy-practice homepage created for the Grow My Therapy front-end internship assignment.

## Overview

This project recreates the supplied reference homepage's layout hierarchy and visual rhythm, then redesigns it for the fictional profile of Dr. Maya Reynolds, PsyD. The copy was manually refined from the supplied profile for clarity, tone, usability and local SEO.

## Features

- Responsive desktop, tablet and mobile layouts
- Accessible navigation and keyboard focus states
- Custom cream, sage and forest-green theme
- Profile-based About, services, approach and FAQ copy
- Three relevant therapy services
- Dr. Maya Reynolds portrait and biography
- New “Our Office” section with supplied office images
- Santa Monica and California-focused SEO metadata

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Check

```bash
npm run lint
npm run build
```

## Main Files

- `app/page.tsx`: homepage structure and content
- `app/globals.css`: theme, layout and responsive styling
- `app/layout.tsx`: metadata and root layout
- `public/images`: supplied therapist and office images

## Content Note

Dr. Maya Reynolds is a fictional therapist profile supplied for this assignment. No unsupported credentials, services or contact information were added.
